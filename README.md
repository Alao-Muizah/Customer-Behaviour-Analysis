# Overview

Analyzed customer behaviour changes over time using transactional data. Instead of static spending, the project focuses on delta (change) features to capture shifts in activity and segment customers into meaningful groups using K-Means clustering.

# Problem

Understanding how spending patterns evolve helps businesses identify high-value, at-risk, or growing customers. Static clustering often misses these behavioural shifts.

# Tools
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn

# Approach & Methodology

Calculated delta features to measure changes in spending across two periods

Determined optimal value for K using silhouette score

Applied K-Means clustering to group customers based on behavioural shifts

Interpreted cluster characteristics to derive actionable insights


# Results

Identified distinct customer segments based on spending changes

Captured behavioural trends not visible in raw transactional data

Enables targeted marketing, retention strategies, and personalized campaigns
